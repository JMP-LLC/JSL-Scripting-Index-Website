## Zugehörige Konstruktoren

### Fit Definitive Screening

**Syntax:** Fit Definitive Screening( Y( column ), X( columns ) )

**Beschreibung:** Analysiert definitive Screening-Designs (DSDs) mithilfe einer Methodik, die Effective Model Selection (effektive Modellauswahl) für definitive Screening-Designs genannt wird. Dieser Algorithmus verwendet die eindeutige Struktur des Designs, um Haupteffekte und Effekte zweiter Ordnung zu identifizieren.

```jsl

Names Default To Here( 1 );
dt = Open( "$SAMPLE_DATA/Design Experiment/Extraction Data.jmp" );
obj = dt << Fit Definitive Screening(
	Y( :Yield ),
	X( :Methanol, :Ethanol, :Propanol, :Butanol, :pH, :Time )
);

```
