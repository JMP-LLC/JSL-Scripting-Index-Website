# Assignment



### Add To

**구문:** y += x; Add To( y, x )

**설명:** 변수 또는 변수 목록에 값을 더한 후 그 결과를 할당합니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

ex = 1;
ex += 2;
ex;

```

### Assign

**구문:** y = x; Assign( y, x )

**설명:** 변수 또는 변수 목록에 값을 할당합니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

{ex1, ex2} = {Pi(), 1};
ex1 + ex1;

```

### Divide To

**구문:** y /= x; Divide To( y, x )

**설명:** 변수 또는 변수 목록을 값으로 나눈 후 그 결과를 할당합니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

ex = 1;
ex /= 2;
ex;

```

### Multiply To

**구문:** y *= x; Multiply To( y, x )

**설명:** 변수 또는 변수 목록에 값을 곱한 후 그 결과를 할당합니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

ex = 3;
ex *= 2;
ex;

```

### PostDecrement

**구문:** x--; PostDecrement( x )

**설명:** 변수 또는 변수 목록에서 1을 뺀 후 그 결과를 할당합니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

ex = 1;
ex--;
ex;

```

**설명:** 변수 또는 변수 목록에 1을 더한 후 그 결과를 할당합니다.

**JMP추가된 버전:** 버전 14 이전

### Subtract To

**구문:** y -= x; Subtract To( y, x )

**설명:** 변수 또는 변수 목록에서 값을 뺍니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

ex;
```
