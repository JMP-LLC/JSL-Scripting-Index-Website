# Trigonometric



## 함수

### ATan

**구문:** y = ArcTangent( x1, <x2=1> )

**설명:** x1/x2의 역삼각 탄젠트를 반환합니다. 여기서 결과는 [-Pi()/2, Pi()/2] 범위에 있습니다.

**JMP추가된 버전:** 버전 14 이전

```jsl

Names Default To Here( 1 );
4 * ArcTangent( 1 );

```
