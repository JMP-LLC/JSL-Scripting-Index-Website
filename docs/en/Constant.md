# Constant



### Pi

**Syntax:** y = Pi()

**Description:** Returns the mathematical constant π, accurate to approximately 15 decimal digits: 3.1415926535....

**JMP Version Added:** Before version 14

```js

Names Default To Here( 1 );
Char( Pi(), 5 );

```
