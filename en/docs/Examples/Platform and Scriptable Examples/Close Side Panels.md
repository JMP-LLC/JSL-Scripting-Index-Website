# Close Side Panels

> **Summary**: Opens and closes side panels in a JMP data table.

<!-- Keywords: #JMPScriptingLanguage, #DataTableManagement, #SidePanels, #Automation, #JSLScript -->

**Code**:
```jsl
dt = Open("data_table.jmp");
dt << Close Side Panels( 1 );
```

**Code Explanation**:

1. Open data table;
2. Close side panels.
