# Web

### Example 1
> **Summary**: Launches web browser to a specific URL.

<!-- Keywords: #Web, #JSL, #URL -->

**Code**:
```jsl
// Web
Web(
	"https://www.jmp.com/en/home"
);
```

**Code Explanation**:

1. Open web browser.
2. Navigate to URL.
