# Statistics

## Marker  Statistics 
> **Summary**: Calculates and visualizes marker statistics for a table, utilizing JMP's built-in Marker Statistics feature.

<!-- Keywords: #JMPScriptingLanguage, #MarkerStatistics, #DataTable, #Statistics, #Automation -->

**Code**:
```jsl
dt = Open("data_table.jmp");
dt << Marker  Statistics();
```

**Code Explanation**:

1. Open table.
2. Run Marker Statistics.
