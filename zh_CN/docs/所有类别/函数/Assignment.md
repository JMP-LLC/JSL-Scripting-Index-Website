# Assignment



### Add To

**语法:** y += x; Add To( y, x )

**说明:** 将一个值添加至变量或变量列表。

**JMP添加的版本:** 早于版本 14

```jsl

ex = 1;
ex += 2;
ex;

```

### Assign

**语法:** y = x; Assign( y, x )

**说明:** 为变量或变量列表赋值。

**JMP添加的版本:** 早于版本 14

```jsl

{ex1, ex2} = {Pi(), 1};
ex1 + ex1;

```
